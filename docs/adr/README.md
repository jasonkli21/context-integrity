# Architecture Decision Records

ADRs capture **durable decisions** that should survive phase completion.

Use an ADR when:

- multiple reasonable architectural options exist;
- a choice materially constrains future work;
- the rationale will matter after the implementation plan is historical.

Do not create ADRs for routine implementation details.

Naming:

```text
0001-short-title.md
0002-short-title.md
```

Use `0000-template.md` as the starting point.
